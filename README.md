# The Keeper's Quest

**Journey into the treacherous forest, discover the secrets within, and save your town.**

A text-based RPG set in a medieval world. Choose one of four classes, build your character's arsenal, and travel through dangers to rescue the town from unspeakable evil.

## Features

- Turn-based battle system driven by character stats: Strength determines how much damage you deal, Defense determines how much damage you block, and Health works as a traditional hit-point system.
- Fully implemented save system — save your game when you end your session and pick up where you left off.
- Fully functioning map that tracks your location as you move around the world.
- Four playable classes:
  - **Warrior** — melee-based, high defense
  - **Rogue** — fast-moving, high health
  - **Hunter** — ranged, high strength
  - **Sorcerer** — magic-wielding, high strength

## Requirements

- Visual Studio 2022 (or later) with the **Desktop development with C++** workload

## To Play

Written in C++ using Visual Studio.

1. Clone the repository:
   ```bash
   git clone https://github.com/Av3Maria/The-Keeper-s-Quest.git
   ```
2. Open `The Keeper's Quest.sln` in Visual Studio
3. Build the solution (`Ctrl+Shift+B`)
4. Run without debugging (`Ctrl+F5` or `Fn+Ctrl+F5` )
5. Choose **New Game**
6. Enter your name and class choice
7. Choose **Save Game** and enter the name of your save file to save your new character
8. Choose **Enter Game** to begin
9. Have fun!
